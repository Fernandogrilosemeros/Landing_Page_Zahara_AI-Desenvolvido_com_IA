# Zahara AI — Website institucional

Site responsivo em HTML, CSS e JavaScript inspirado na identidade visual fornecida.

## Arquivos
- `index.html`: estrutura e conteúdo
- `style.css`: identidade visual, responsividade e animações
- `script.js`: menu, navegação ativa, depoimentos, modal e formulário
- `image.png`: referência visual enviada e usada como fundo do bloco de vídeo

## Como abrir
Abra `index.html` em qualquer navegador moderno. Para desenvolvimento, use a extensão **Live Server** do VS Code.

## Personalizações importantes
1. Substitua nomes, cargos e placeholders da equipe pelos dados e fotos oficiais.
2. Troque clientes/parceiros e depoimentos demonstrativos por conteúdo autorizado.
3. Atualize certificações apenas quando houver comprovação oficial.
4. Substitua o bloco de vídeo no modal por um `<video>` MP4 ou iframe do YouTube/Vimeo.
5. Conecte o formulário a um backend, Microsoft Power Automate, Formspree ou HubSpot.
6. Para reproduzir exatamente o logotipo, adicione os arquivos oficiais em SVG/PNG e a fonte licenciada.
